# Angie's Little Italy – Pizza Shop Website

Static one-page website (HTML + CSS + JS, no build step).

## Files
- `index.html` – the whole site
- `images/` – photos used by the site (replace with your own, keep the same file names)

## Publish on GitHub Pages
1. Create a repository and upload everything in this folder (keep `images/` next to `index.html`).
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. Your site goes live at `https://<username>.github.io/<repo>/` after about a minute.

## Notes
- The reservation form and newsletter box are demos and do not send data yet.
- Review cards are sample text; replace them with real reviews.
